Good reading experiences are often built from details that almost disappear: a visible focus ring, a useful skip link, a line length that never asks too much of the eye.

<!-- more -->

Still keeps those details close to the foundation. Its markup is semantic, its motion respects reduced-motion preferences, and its print styles remove the interface when paper is the better medium.

The JavaScript is deliberately small. It handles color mode and local search, then steps aside.

## A short checklist

1. Start with meaningful HTML.
2. Make every control work from a keyboard.
3. Keep contrast strong in both color modes.
4. Ship only the code the reader needs.

That is enough for a quiet theme to feel considered rather than empty.
